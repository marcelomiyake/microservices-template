# Architecture decision records

The two baseline records describe why this starter uses Rust and Vue. They are template decisions; generated projects should keep, amend, or supersede them based on their own constraints.

- [ADR-0001: Rust backend services](0001-use-rust-for-backend-services.md).
- [ADR-0002: Vue web frontend](0002-use-vue-for-web-frontend.md).

For a new decision, copy [the ADR template](../templates/adr.template.md), use the next zero-padded number, and link it here and from [the documentation index](../README.md). Do not rewrite an accepted past decision to hide a later change.
